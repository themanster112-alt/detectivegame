# إصلاح عرض التحقيق — 2026-10-28

التغييرات للعرض فقط. بقيت قضية المكالمة الأخيرة وحقيقتها ومعايير الاتهام والنتائج والمحرك وملفات تعريف الحفظ دون تعديل.

- الاستكشاف: الخلفية ومؤشرات «تحدث» و«افحص» المرتبطة بالمناطق الفعلية. لا صورة نصفية عائمة ولا صور أدلة موضوعة فوق الخلفية.
- الحوار: متحدث واحد؛ صورة الشخصية على اليسار وصندوق سفلي يبدأ عند 60% من ارتفاع الشاشة. الصورة تحت الصندوق، فيغطي أسفلها عمدًا ويبقى الوجه ظاهرًا. اسم الشخصية داخل الصندوق.
- البطل: أزيلت الأيقونة المصغرة؛ صورة مناسبة لحجم الشاشة أثناء اختيار السؤال أو التفكير، وصورة الاتهام في المواجهة. لا تُركّب صورته فوق صورة المتحدث الآخر.
- الأدلة: الفحص الأولي مدمج؛ بعد الجمع تفتح نافذة أكبر وصورة كاملة بارتفاع 220، وتظهر الصورة في الدفتر وتفاصيله. تبقى شروط حجب صور المراقبة والصورة القديمة فعالة حتى لا تنكشف معلومات غير مكتشفة.
- أصلح عداد صفحات التقارير: اتجاه LTR للعدد ومنع التفافه؛ لا يمدّد أزرار التنقل أو يحجب صورة التقرير.

## التحقق الرسومي الفعلي
