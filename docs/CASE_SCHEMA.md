# عقد القضايا — schema_version 2

القضية وحدة JSON مستقلة، ومعرّفها فريد بين ملفات data/cases/. نقطة البداية data/templates/case_template.json. القالب صالح بنيويًا لكنه يحتاج محتوى وقواعد تقييم من الكاتب؛ لا يقدّم المحرك سيناريو تلقائيًا.

## الحقول الرئيسية

| الحقل | الغرض |
| --- | --- |
| schema_version | الرقم 2؛ الصيغة 1 القديمة تُحوّل عبر legacy_case_adapter.gd |
| revision | رقم إصدار موجب؛ الحفظ يرتبط أيضًا ببصمة المحتوى |
| id / title | هوية ثابتة وعنوان عربي |
| target_duration_minutes | مدة مستهدفة، افتراضيًا 15؛ ليست مؤقتًا |
| case_file | number، crime_type، crime_label، summary، victim.name، victim.background، crime_scene |
| assistant | name وbriefing؛ يضاف عرض الأشخاص والمواقع من القوائم |
| start_location | معرّف موقع البداية |
| locations | معرّف وname وdescription وrequires اختياري؛ art اختياري لتعيين خلفية الكتالوج |
| people | شخصيات متغيرة العدد، موضحة أدناه |
| evidence | الأدلة والأماكن والإحداثيات والبيانات الوصفية |
| statements / questions / facts | الأقوال والأسئلة والحقائق الخاصة وصياغاتها |
| reports / timeline | التقارير وتحديثاتها والأحداث الزمنية |
| inference_options / inferences / contradictions | تفسيرات اللاعب والروابط المسنودة والتناقضات القابلة للكشف |
| truth / assessment | حقيقة الجريمة وقواعد المراجعة الخاصة، لا ترسل للواجهة أو المزوّد |
| campaign_effects / requirements | أثر النتيجة وشروط الحملة |
| allow_reopen | السماح بإعادة الفتح، افتراضيًا true |
| accusation_label | صياغة زر الاتهام، اختيارية، بلا تلميح إلى الشخص الصحيح |
| visual_catalog_path | مورد .tres محلي للأصول؛ فارغ يعني كتالوجًا عامًا دون صور مفترضة |

crime_type يقبل أنواعًا مختلفة، ويستخدم murder لفرض وجود تقرير forensic أولي. الأنواع الأخرى تستخدم technical أو نوع تقرير يحدده الكاتب. crime_scene نص أو معرّف موقع يُعرض باسمه.

## الشخصيات

كل شخصية: id، name، role: witness أو suspect أو both، occupation اختياري، location_id أو سلسلة فارغة للشخصيات التي تُستدعى دون موضع ثابت، position من إحداثيين نسبيين، statement_ids، requires اختياري، art_id اختياري، وai.

بيانات ai:
- personality وspeech_style: وصف الأسلوب، ويمكن تركهما فارغين في بيانات التدريب.
- knows: معرّفات ما تعرفه الشخصية.
- conceals: معرّفات معلومات تخفيها، مع شروط كشف على الحقائق والأسئلة.
- lies: معرّفات الأقوال الكاذبة المعتمدة من الكاتب؛ لا تغيّر الحقيقة الفعلية.
- known_evidence: الأدلة التي يمكن أن تعرفها الشخصية. لا يُمرر منها للمزوّد إلا المكتشف.

يسمح باستدعاء أي شخصية متاحة من أي موقع. لا يشترط سماع كل الأقوال قبل طرح الأسئلة. وجود شخصية في أحد المواقع يضيف نقطة تفاعل لها؛ يُعرض المتحدث النشط فوق الخلفية.

## الأدلة والأقوال والأسئلة

الدليل: id، name، description، source، time، category، location_id، position، وrequires اختياري. الإحداثيات بين 0.08 و0.85 للحفاظ على مناطق اللمس. وقت الدليل نص وصفي؛ لا يحوّل المحرك الوقت غير المؤكد إلى حقيقة مؤكدة.

القول: id، person_id، text، status من claimed / confirmed / uncertain، وrequires. يجب أن تنتمي معرّفات statement_ids للشخصية نفسها. يُحفظ القول عندما يصل إليه اللاعب، ويمكن الرجوع إليه في اللوح والدفتر.

السؤال: id، person_id، label، answer_facts، وrequires. لا تحمل الواجهة نص الإجابة؛ تُستخرج الصياغة من الحقائق المسموحة بعد تطبيق الشروط.

الحقيقة الخاصة: id، text، variants اختياري (صياغات مكافئة معتمدة)، وrequires. لا تظهر هذه القائمة كاملة للاعب أو للمزوّد. يمكن أن يكون النص قولًا معتمدًا لشخصية كاذبة؛ حقيقة الجريمة نفسها تبقى في truth.

## الشروط

requires كائن يجمع شروط AND من قوائم المعرّفات التالية: evidence، statements، questions، reports، people (سبق التواصل)، inferences، contradictions. يمكن إضافة global.

مثال:

```json
{
  "requires": {
    "evidence": ["sample"],
    "contradictions": ["contradiction_a"],
    "global": {"reputation_min": 1}
  }
}
```

global يدعم reputation_min، trust_min: {person_id: number}، flags: {key: value}، judgments: {case_id: decision_or_audited_outcome}. القرار العام هو charge_established أو insufficient. نتائج proven / failed / wrongful_verdict لا تطابق شرطًا إلا بعد التدقيق؛ لا تُستعمل كقناة لتسريب حقيقة مخفية.

لا تضع في شروط بدء القضية متطلبات تقدم من القضية نفسها؛ استخدم شروط الحملة هناك. الشروط المحلية تفتح محتوى إضافيًا، ولا تمنع تقديم اتهام جزئي.

## التقارير والخط الزمني

التقرير: id، title، kind، summary، status: preliminary / confirmed / uncertain، findings (قائمة نصوص)، cause_of_death وestimated_time عند الانطباق، requires، وsupersedes اختياري للإشارة إلى تقرير سابق. يلزم تقرير أولي متاح أثناء الإحاطة، وفي القتل يكون forensic.

يظهر التقرير الأولي بما فيه من عدم يقين. التقرير الجديد لا يمحو القديم؛ تُعرض الإشارة إلى تحديثه. شروط الأدلة أو الأقوال أو التناقضات قد تفتح تحديثًا لاحقًا.

الحدث الزمني: id، time، text، status، order رقمي، requires. ترتب الأحداث بقيمة order التي يحددها الكاتب، لا بقراءة نص الوقت. الأوقات التقريبية والفرضيات تبقى موسومة.

## مراجع لوح التحقيق

| السابقة | العنصر |
| --- | --- |
| e: | دليل مكتشف |
| s: | قول سمعه اللاعب |
| q: | إجابة استجواب مسجلة |
| p: | شخصية سبق التواصل معها |
| r: | تقرير متاح |
| t: | حدث زمني متاح |
| i: | استنتاج مسنود |
| c: | تناقض موثق |
| h: | فرضية أنشأها اللاعب |

لا تستخدم النقطتين داخل معرّفات السجلات الأصلية. inference_options: قوائم id وlabel للتفسيرات. inferences: id، meaning الذي يشير إلى تفسير، links من مرجعين مختلفين على الأقل، explanation، requires.

كل ربط آخر صالح بين عناصر يعرفها اللاعب يُحفظ كفرضية، دون وسمه بأنه الحل الخاطئ أو كشف الحل الحقيقي. يمكن ربط دليل بقول أو شخص أو تقرير أو أحداث، وليس الأدلة ببعضها فقط.

التناقض: id، person_id، question_id، evidence_id، explanation، requires. يلزم طرح السؤال وامتلاك الدليل والشخصية النشطة المناسبة، ولا يلزم استكمال شهادة كاملة أو كل التناقضات.

## تقييم الاتهام والنتائج

truth يحوي culprit_ids غير فارغة وsummary. لا توجد هوية جانٍ ثابتة في السكربتات.

assessment يحوي threshold موجبًا وminimum_groups موجبًا وprofiles. كل profile يحوي suspect_id وcriteria. لكل معيار id وall_of (المراجع التي يجب إرفاقها معًا)، weight موجب، group، وreliability: valid أو misleading.

- يُقيّم الملف المرفق لحظة الاتهام؛ اكتشاف دليل بعده لا يضيفه بأثر رجعي.
- الأدلة أو الاستنتاجات غير المعروفة لا تُقبل للإرفاق، والتكرار لا يرفع القوة.
- يمكن إنشاء معايير بديلة لنفس المشتبه به؛ لا توجد قائمة إلزامية واحدة في المحرك.
- إذا لم يكفِ الوزن وتنوع المجموعات تكون النتيجة failed.
- الملف الكافي بمواد مسنودة لهوية فعلية صحيحة يعطي proven.
- الملف المقنع القائم على مواد مضللة أو الموجه لغير المرتكب يعطي wrongful_verdict.

submit_accusation يسجل pending فقط. review_accusation يصدر قرارًا عامًا دون كشف النتيجة الفعلية. audit_accusation عملية اختيارية صريحة تكشف النتيجة والحقيقة المعدّة من الكاتب. reopen_case يعيد التحقيق دون حذف التقدم أو الأحكام.

campaign_effects يعرّف لكل نتيجة تغير reputation وtrust وflags. يُطبق أثر الفشل العام عند القرار. الآثار التي تعتمد على الحقيقة تنتظر التدقيق، حتى لا تكشف واجهة السمعة حكمًا خاطئًا فورًا. يُطبق كل أثر مرة واحدة.

## التوافق والاختبار

مثال التدريب v1 محفوظ كما هو. يحول المحوّل الشاهد الواحد إلى شخصية وأقوال، والمشتبه بهم إلى قائمة مستقلة، وقواعد الإثبات إلى معايير بيانات. لا يُستخدم اسم سامر أو ليلى لتحديد الحل داخل المحرك.

tests/fixtures/engine_contract.json مثال تقني قصير للبنية: جريمة قتل تجريبية، ست شخصيات، ثلاثة مواقع، تقرير أولي وتحديث، ومسارات مختلفة للاتهام. ليس سيناريو نهائيًا. شغّل test_general_engine.gd بعد تأليف أي تعديل بنيوي.

## التحاليل المطلوبة ومناطق الفحص المشتركة

يدعم سجل التقرير الحقل الاختياري `request_required: true` و`analysis_label`. بعد تحقق `requires` يظهر الطلب في `available_analyses()` دون محتوى النتيجة. ينشر `request_analysis(id)` النتيجة فورًا ويحفظ الطلب ضمن `requested_analyses`. غياب الحقل يبقي النشر التلقائي السابق؛ الحفظ القديم الذي لا يتضمن قائمة الطلبات يظل صالحًا عند عدم وجود نتائج يدوية منشورة.

يمكن لموضع فحص الدليل تعريف `area_id` و`area_label` بجانب المستطيل المطبّع. تجمع الأدلة ذات المنطقة الواحدة في زر فحص واحد ونافذة اختيار؛ تبقى معرفات الأدلة ومدخلات جمعها مستقلة. يجب توحيد المستطيل والعنوان لأعضاء المنطقة وتجنب تداخل المناطق المختلفة. لا يفتح اختيار المنطقة الأدلة أو التحاليل تلقائيًا.

## إبطال معيار اتهام بمواد نفي

يمكن لمعيار assessment إضافة `none_of: ["r:report_id", ...]`. إذا أرفق اللاعب أي مرجع منها في ملف الاتهام، لا يحتسب وزن هذا المعيار. يتحقق المدقق من صحة المراجع كما يفعل لـ all_of. غياب الحقل يعادل قائمة فارغة ويحافظ على السلوك السابق. التقييم ثابت على المواد المرفقة لحظة تقديم الاتهام، وليس جميع الاكتشافات اللاحقة.

يدعم العرض الاختياري `presentation.closing_hint` بحقلَي `title` و`text`. لا يعرض النص إلا في نافذة القرار أو السجل عندما تكون القضية مغلقة، وتستعاد إمكانية عرضه من حالة القضية المحفوظة.
