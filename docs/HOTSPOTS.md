# مناطق فحص موقع الجريمة

طبقة عرض فقط؛ لم تتغير ملفات المحرك أو حقائق القضايا. لا تُعرض أسماء الأدلة أو صورها فوق المشهد. مناطق الفحص شفافة، ويظهر إطار خفيف عند المرور أو التركيز أو الضغط فقط، دون اسم الدليل. الفحص لا يجمع الدليل تلقائيًا؛ يظهر زر الجمع للعنصر القابل للجمع، ثم يصبح متاحًا في دفتر الأدلة.

## تعريف من ملف القضية

يمكن إضافة بيانات عرض إلى JSON دون تغيير قواعد التحقيق:

```json
{
  "presentation": {
    "hotspots": [
      {
        "id": "desk_search",
        "location_id": "office",
        "evidence_id": "phone",
        "rect": [0.345, 0.51, 0.10, 0.075],
        "label": "تفتيش سطح المكتب",
        "art_match": false,
        "collectible": true
      },
      {
        "id": "wall_detail",
        "location_id": "office",
        "rect": [0.74, 0.35, 0.08, 0.10],
        "label": "فحص الجدار",
        "description": "وصف العنصر من إعداد كاتب القضية.",
        "art_match": true
      }
    ]
  }
}
```

المثال يوضح البنية فقط. evidence_id يشير إلى دليل موجود أصلًا. عدم وجوده يعني عنصر فحص وصفيًا بلا جمع أو تغيير لحالة التحقيق. تظل أوصاف الأدلة القابلة للجمع مأخوذة من بيانات القضية نفسها.

rect هو [x, y, width, height] بين 0 و1 بالنسبة لصورة الخلفية المعروضة، مع حساب الهوامش الناتجة عن اختلاف النسب. يتوسع الهدف إلى 64×64 على الأقل لدعم اللمس، ويبتعد عن العنوان والشريط السفلي.

art_match=false يعني أن القطعة نفسها غير مرسومة بوضوح، وتعرض نافذة الفحص توضيحًا مقتضبًا بأن الموضع تقريبي. لا يُضاف أي رسم يوهم اللاعب بوجود قطعة في الصورة. استخدم label عامًا للمنطقة، لا اسم الدليل السري.

## بدائل تعريف العرض

يمكن وضع الكائن نفسه داخل الدليل في الحقل hotspot، أو تعريف inspection_regions داخل مورد Visual Catalog الخاص بالقضية بمفتاح location_id:evidence_id. في المورد تُكتب rect كـ Rect2. الأولوية: presentation.hotspots ثم evidence.hotspot ثم كتالوج الأصول، ثم position القديم كمنطقة بحث تقريبية.

كتالوج التدريب الحالي يضع فحص الكوب فوق الكوب الموجود في الخلفية، وفحص الهاتف والرسالة فوق مناطق أوراق مناسبة مع توضيح أنهما منطقتا بحث تقريبيتان. لم تُعدّل بيانات الأدلة الأصلية.

## الواجهة والاختبار

نافذة الفحص 46% من عرض الشاشة و62% من ارتفاعها تقريبًا، وتعرض الوصف وزر الجمع عند توفره. لا تظهر تسمية الدليل قبل جمعه، ولا توجد عبارة صورة دليل مؤقتة في المشهد أو بطاقات الأدلة.

الشريط السفلي مستقل عن ارتفاع محتوى الشاشة، مثبت داخل الهوامش الآمنة، ويحتوي أربع خانات ذات أهداف لمس لا تقل عن 64 بكسل. زر توجيه اتهام واضح في الشريط، مع اختصار أثناء النوافذ والحوار.

tests/test_crime_scene.gd يختبر اللمس الفعلي داخل Godot، والفحص والجمع وعدم كشف الأسماء والعناصر غير القابلة للجمع وإحداثيات JSON والتنقل والاتهام، وقياسات 1280×720 و1600×720 و1280×800. هذا فحص محرك ورسوم محلي، وليس اختبار جهاز هاتف فعلي.
